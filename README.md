# Telegram бот для записи на консультацию ITty Company

Telegram-бот для записи клиентов на консультацию с удобным интерфейсом и системой управления записями.

## ✨ Возможности

### Для клиентов:
- 📅 **Запись на консультацию** через удобную форму с выбором типа консультации
- 📋 **Просмотр своих записей** с возможностью отмены
- ❓ **FAQ раздел** с ответами на частые вопросы
- ℹ️ **Информация о компании**
- 🔔 **Уведомления** о статусе записи (подтверждение/отклонение)
- 🤖 **AI-ассистент** - отвечает на вопросы и помогает с консультациями
- 💬 **Поддержка групповых чатов** - бот отвечает на упоминания в группах
- 🧹 **Очистка контекста** - команда /clear для начала нового диалога

### Для администратора:
- 🔔 **Автоматические уведомления** о новых заявках с кнопками подтверждения/отклонения
- 📊 **Статистика записей** (всего, ожидают, подтверждены, отменены)
- 👀 **Просмотр всех записей** через команду `/admin`
- ✅ **Подтверждение/отклонение записей** прямо из Telegram
- 📱 **Уведомления пользователей** при изменении статуса
- 📊 **Интеграция с Google Sheets** - все заявки автоматически сохраняются в таблицу
- 🔗 **Прямой доступ к таблице** через кнопку в админ-панели

### Технические:
- 💾 Сохранение данных в JSON файл
- 📊 Автоматическое сохранение в Google Sheets (опционально)
- 🎨 Удобный интерфейс с кнопками
- ⚙️ Настраиваемые типы консультаций
- 🏢 Настраиваемое название и описание компании

## Установка

1. **Клонируйте репозиторий или скачайте файлы**

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Создайте бота в Telegram:**
   - Откройте [@BotFather](https://t.me/BotFather) в Telegram
   - Отправьте команду `/newbot`
   - Следуйте инструкциям и получите токен бота

4. **Получите ваш ID администратора:**
   - Откройте [@userinfobot](https://t.me/userinfobot) в Telegram
   - Скопируйте ваш ID (число)

5. **Настройте конфигурацию:**
   - Скопируйте файл `env.example` в `.env`
   - Откройте `.env` и заполните **обязательные** переменные:
     ```
     BOT_TOKEN=ваш_токен_от_BotFather
     ADMIN_ID=ваш_telegram_id
     ```
   - Остальные переменные опциональны (AI, Google Sheets и т.д.)
   
6. **Настройка Google Sheets (опционально):**
   - Все заявки автоматически сохраняются в Google Таблицу
   - Подробная инструкция: [GOOGLE_SHEETS_SETUP.md](GOOGLE_SHEETS_SETUP.md)
   - Добавьте в `.env`:
     ```env
     # Google Sheets настройки
     USE_GOOGLE_SHEETS=true
     GOOGLE_SHEET_ID=ваш_SPREADSHEET_ID_здесь
     GOOGLE_SHEET_NAME=Заявки
     GOOGLE_CREDENTIALS_FILE=credentials.json
     ```

## Использование

### Для пользователей:

1. Найдите вашего бота в Telegram и нажмите `/start`
2. **Используйте AI-ассистента** - просто напишите боту любое сообщение, и он ответит!
3. Используйте кнопку "📅 Записатися на консультацію" для создания новой записи
4. Заполните форму:
   - **Выберите тип консультации** (из предложенных вариантов)
   - Имя
   - Контакт (телефон или email)
   - Дата консультации
   - Время консультации
   - Тема консультации
5. Подтвердите заявку
6. Просматривайте свои записи через "📋 Мої записи"
7. Отменяйте записи прямо из раздела "Мои записи"
8. Используйте `/clear` для очистки контекста диалога с AI

**AI-ассистент:**
- Просто напишите боту сообщение - он ответит на ваши вопросы
- Бот помнит контекст разговора (последние 20 сообщений)
- В групповых чатах бот отвечает на упоминания (@bot_username)
- Используйте `/clear` чтобы начать новый диалог

### Для администратора:

- Используйте команду `/admin` для просмотра статистики и последних записей
- Получайте автоматические уведомления о новых заявках с кнопками:
  - ✅ **Подтвердить** - подтверждает запись и уведомляет клиента
  - ❌ **Отклонить** - отклоняет запись и уведомляет клиента
- Получайте уведомления, когда клиенты отменяют свои записи
- **Просмотр Google Таблицы** - нажмите кнопку "📊 Открыть Google Таблицу" в админ-панели для просмотра всех заявок

## Деплой на VPS (Ubuntu/Debian) 24/7 через systemd

Рекомендуемый путь приложения на сервере: `/opt/chat-bot`.

1) Скопируйте проект на VPS в `/opt/chat-bot` (scp/rsync/SFTP).

2) На VPS создайте `.env`:

```bash
cd /opt/chat-bot
cp env.example .env
nano .env
```

Минимум заполните `BOT_TOKEN` и `ADMIN_ID`.

3) Запустите установку (один раз):

```bash
cd /opt/chat-bot
chmod +x deploy/vps_install.sh deploy/vps_update.sh
./deploy/vps_install.sh
```

4) Проверка:

```bash
sudo systemctl status chat-bot --no-pager
sudo journalctl -u chat-bot -f
```

5) Обновление кода/зависимостей:

- обновили файлы в `/opt/chat-bot` (git pull или загрузили заново)
- затем:

```bash
./deploy/vps_update.sh
```

## Деплой на Render (24/7 без VPS)

Render лучше всего подходит для вашего бота как **Background Worker** (polling).

### 1) Залейте проект в GitHub

Render разворачивает проекты из репозитория. Если у вас ещё нет репо:

```bash
git init
git add .
git commit -m "Initial commit"
```

Дальше создайте репозиторий на GitHub и сделайте push (в GitHub будет подсказка команд).

### 2) Создайте сервис в Render

1. В Render: **New** → **Blueprint** и выберите репозиторий.
2. Render подхватит `render.yaml` и создаст сервис `chat-bot` типа **worker**.
3. В настройках сервиса задайте переменные окружения (**Environment**):
   - обязательно: `BOT_TOKEN`, `ADMIN_ID`
   - опционально: `CONSULTANT_ID`, `CONSULTANT_USERNAME`, AI, Google Sheets

### 3) Важно про хранение данных

На Render файловая система может быть не постоянной (при деплоях/рестартах).
Если вам важно сохранять данные (например, локальные `*.json`) — используйте:
- Google Sheets (`USE_GOOGLE_SHEETS=true`), или
- Persistent Disk (платная опция на Render).

## 📝 Настройка под вашу компанию

### Изменение названия компании

Откройте `config.py` и измените:
```python
COMPANY_NAME = 'Ваша Компания'
COMPANY_DESCRIPTION = 'Ваше описание'
```

Или добавьте в `.env`:
```
COMPANY_NAME=Ваша Компания
COMPANY_DESCRIPTION=Ваше описание
```

### Настройка типов консультаций

В файле `config.py` измените список:
```python
CONSULTATION_TYPES = [
    'Ваш тип 1',
    'Ваш тип 2',
    'Ваш тип 3',
]
```

### Настройка AI-ассистента

По умолчанию бот использует простые шаблонные ответы. Для подключения реального AI:

1. **OpenAI API** (рекомендуется):
   - Получите API ключ на [platform.openai.com](https://platform.openai.com)
   - Добавьте в `.env`:
     ```
     USE_AI_API=true
     OPENAI_API_KEY=your_openai_api_key_here
     ```

2. **DeepSeek API** (если доступно):
   - Получите API ключ на сайте DeepSeek
   - Добавьте в `.env`:
     ```
     DEEPSEEK_API_KEY=your_deepseek_api_key_here
     ```

Без API ключа бот будет работать с базовыми шаблонными ответами, которые покрывают основные вопросы.

## Данные

Все записи сохраняются в файл `bookings.json` в формате JSON. Каждая запись содержит:
- ID записи
- ID пользователя Telegram
- Имя пользователя
- Контактные данные
- Тип консультации
- Дата и время консультации
- Тема консультации
- Статус (pending/confirmed/cancelled)
- Дата создания

## Безопасность

- Не публикуйте файл `.env` с токенами
- Файл `bookings.json` содержит персональные данные - храните его в безопасности
- Используйте `.gitignore` для исключения чувствительных файлов
